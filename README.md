# java-lotto-precourse
## 기능 목록
## 입력 기능
- [x] 로또 구입 금액 입력 받기
- [x] 당첨 번호 쉼표(,) 기준으로 6개 입력 받기
- [x] 보너스 번호 입력 받기

## 로또(Lotto, WinningLotto)
- [x] 입력 받은 숫자들을 리스트로 관리
- [x] 보너스 숫자는 따로 관리
- [x] 입력 받은 로또 숫자 공백제거

## 로또 발행(LottoGenerator)
- [x] 구입금액을 기준으로 시행횟수 계산(1장당 1,000원)
- [x] 6개의 숫자를 중복없이 랜덤으로 뽑기 (1~45의 숫자 중)
- [x] 생성 된 숫자 오름차순 정렬

## 로또 결과 비교
- [x] 매치되는 숫자개수 계산
- [x] 보너스 숫자 포함 여부 확인
- [x] 등수 판별

## 수익률 계산
- [x] 총 당첨금 / 구입금액 (소수점 2자리에서 반올림) * 100 

## 예외 처리
- [ ] 입력 받은 숫자가 1~45 사이가 아닌 경우
- [ ] 보너스 번호가 입력 받은 숫자가 같은 경우
- [ ] 빈 문자열이 들어왔을 경우
- [ ] 입력 받은 숫자가 6개가 아닐 경우
- [ ] 로또 구입 금액이 1,000원 단위가 아닐 경우
- [ ] 로또 구입 금액이 양수가 아닌 경우

## 출력 기능

- [x] 발행한 로또 수량과 번호를 출력
- [x] 당첨 내역 출력
- [x] 총 수익률 출력(소수점 둘째 자리 반올림)

## 테스트
- [ ] 로또 번호 생성 테스트
- [ ] 로또 번호 검증 테스트(1~45)
- [ ] 등수 판별 테스트
- [ ] 예외 처리 테스트
- [ ] 수익률 계산 테스트
